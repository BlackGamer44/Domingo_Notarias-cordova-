# Domingo_Notarias-cordova-
proyecto de apache Córdova de notarias

# importante
para que funcione se deve de colocar en **www** del proyecto de apache cordova y para que funcione a la con la base de datos deven tener la api creada en php (local o enlinea)

y crear un **tunel** con **cloudflare tunnels** y agregar la url del tunel en el archivo **config.js** (solo remplasan la url que ya tiene el archivo).
